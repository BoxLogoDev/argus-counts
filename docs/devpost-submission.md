# Argus — 제출 문안 패키지

이 문서는 제출 플랫폼(Devpost 형식) 입력 칸에 그대로 옮겨 넣을 문안이다.
현재 상태는 데모 계수가 모의 어댑터 동작 중이며 SAM 3.1 실호출은 단일 빈 스모크로 검증했고 Pi 실촬영은 검증 전이다.
블로커가 남아 있는 동안 제출 상태는 `SUBMISSION_READY: false` 그대로 둔다.

## 프로젝트 이름

- Argus (아르고스)

## 한 줄 소개

- 창고 빈(bin)을 촬영하면 AI가 수량을 세고 장부와 대조해 차이 리포트를 만드는 재고실사 코파일럿.

## 소개

창고 실사는 사람이 빈마다 돌아다니며 수량을 세어 장부와 맞추는 작업이다.
빈이 많을수록 시간이 오래 걸리고, 세는 과정과 옮겨 적는 과정에서 오차가 생긴다.
Argus는 그 흐름을 촬영→계수→대조→리포트로 줄여, 차이나는 빈부터 조치하게 한다.
이 문안의 설명은 전부 공개 자료와 독립적으로 만든 가상 데모 데이터 기준이다.
실제 회사 자료는 코드·문서·데모 어디에도 넣지 않는다.

## 동작 방식

1. 촬영 — 단말 또는 Pi 카메라로 빈을 촬영한다.
2. 계수 — SAM 3.1 어댑터가 사진에서 수량을 산출한다.
3. 대조 — 장부 수량과 비교해 일치·부족·초과를 판정한다.
4. 리포트 — 차이 목록·조치 우선순위·영향 수치를 생성한다.

위 흐름의 계수는 현재 모의 어댑터 기준으로 동작한다.

## Meta AI 도구 활용

- SAM 3.1을 Meta Model API로 쓰는 구조이며, 연동 지점은 어댑터 1곳으로 격리돼 있다.
- 데모 계수는 모의 어댑터가 동작 중이지만 SAM 3.1 실호출은 단일 빈 스모크로 검증했다(2026-10-30).
- 실호출 코드 경로(LiveSamCounter)는 커넥터 경유 단일 빈 스모크에서 실제 API로 검증했고(생성한 가상 창고 사진에서 박스 14개 계수, 장부 8, 차이 +6), 단위 테스트에서는 가짜 transport로도 검증한다.
- 크레딧 입금은 2026-10-29 확인했고, API 키는 Secure Vault 경유로만 받으며 값은 문서에 적지 않는다.
- 전체 세션 실호출은 아직 하지 않았고, 기본 데모 실행의 계수는 모의 어댑터 기준이다.
- 환경변수는 `SAM_API_BASE_URL`과 `SAM_API_KEY`이며, 값 자체는 문서에 적지 않고 존재 여부만 확인한다.
- 테마는 Build for Your World 가안이며, 확정 전까지 제출 서술의 테마 문구는 가안으로 유지한다.

## 기술 구성

- Python 3 표준 라이브러리 중심의 단말 플로우(시뮬레이터·사진 입력·Pi 캡처/세션 경계)
- 웹 콘솔(http.server 기반 — 실사 세션·차이 목록·요약 지표·준비 상태 패널)
- 장부 대조 엔진과 조치 우선순위를 포함한 차이 리포트 파이프라인
- QA 하네스(기준값 대조 체크 17개)와 현재형 주장 감사·standalone·전수 점검 하네스
- 단위 테스트 — 개수는 숫자로 단정하지 않고 `python3 -m unittest discover -s tests` 실행으로 확인한다
- 프로젝트 로컬 검증 스킬(verify-argus — 앱을 사용자처럼 구동해 증거를 남긴다)
- ffmpeg 기반 데모 영상 초안 렌더러(컷별 슬라이드와 실데이터 패널 합성)

## 데모 데이터

- 데모 기준: 빈 6개 중 일치 4건, 불일치 2건이다.
- 데모 기준: 절대 차이 6개, 순차이 0, 일치율 66.7%이다.
- 위 수치는 전부 데모 기준이며 실제 창고 성과가 아니다.

## 해커톤 기간 중 신규 제작

- 기존에 있던 것은 문제의식과 도메인 지식뿐이며, 제출하는 코드·문서·영상 자산은 전부 해커톤 기간(2026-10-27~11-04) 안에 새로 작성했다.
- 제출 저장소는 기존 프로젝트와 분리한 standalone 구성이다.

## 데모 영상

- 3분(180초) 초안이 렌더돼 있고 컷 9개로 구성된다.
- 컷 3은 Pi 실촬영 교체 예정인 플레이스홀더 슬라이드이다.
- 전 컷 하단에 모의 데이터·데모 기준 표기가 들어간다.

## 현재 블로커와 제출 상태

- 남은 블로커는 1건이다.
- `pi_real_capture_pending`
- 현재 정답은 `SUBMISSION_READY: false` 다.
- 공개 저장소: https://github.com/BoxLogoDev/argus-counts
- 제출 마감은 2026-11-04 21:00 ET = 2026-11-05 11:00 KST이며, 지각 제출은 고려되지 않는다.

## 제출 전 교체할 항목

- SAM 실호출은 단일 빈 스모크까지 검증했으며, 제출 전에는 전체 세션 실호출 범위를 확정해 Meta AI 도구 활용 절에 반영할 예정이다.
- Pi 실촬영으로 데모 컷 3을 교체할 예정이다.
- 최종 수치는 제출 전 전수 점검(`python3 -m qa.pre_submission`) 출력으로 다시 확인한다.
