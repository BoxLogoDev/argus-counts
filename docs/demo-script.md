# Argus 데모 영상 대본. 총 3분

테마는 Build for Your World를 전제로 한다. 주인님 최종 확정 전 가안이다.

기존과 신규 구분 한 줄은 영상 첫머리 0분 00초부터 0분 18초 구간(컷 1)에 자막과 나레이션으로 넣는다. 위치는 제목 화면 바로 아래다. 컷 1과 컷 9는 나레이션 속도(공백 제외 글자수/초 4.0 이하)를 맞추기 위해 구간을 재조정했다 — 컷 1은 컷 2에서, 컷 9는 컷 8에서 시간을 가져왔고 나레이션 문장은 그대로다.

기존에 있던 것은 Meta SAM 3.1과 Meta Model API와 Python 표준 라이브러리와 하드웨어 플랫폼이다. 이번에 만든 것은 이 저장소의 모든 코드와 문서이며 2026-10-27 이후 해커톤 기간에 새로 작성했다.

모든 코드는 해커톤 기간인 2026-10-27 이후에 새로 작성됐다.
SAM 3.1 실호출은 아직 하지 않았다.
현재는 모의(mock) 어댑터로 동작한다.
크레딧 입금 확인 후 실호출로 전환할 예정이다.
Pi 실기 카메라 연동은 아직 검증 전이다.
예시는 전부 가상 데모 데이터다.

## 촬영 체크리스트

- 첫 장면이 단말 실동작 화면인지 확인한다. 시뮬레이터나 콘솔 화면이어야 한다.
- 기존과 신규 구분 한 줄이 첫머리 제목 바로 아래에 보이는지 확인한다.
- 모의 표기가 화면에 보이는지 확인한다. 계수 출처가 모의로 읽혀야 한다.
- SAM 실호출을 한 것처럼 말하지 않는지 확인한다. 대본은 실호출 전과 전환 예정으로 말해야 한다.
- Pi 실촬영 컷 자리에 Pi 도착 후 교체 플레이스홀더가 보이는지 확인한다.
- Pi 실기 검증을 마친 것처럼 말하지 않는지 확인한다. 대본은 검증 전으로 말해야 한다.
- 수치가 데모 기준인지 확인한다. 빈 6개와 일치 4건과 불일치 2건과 절대 차이 6과 일치율 66.7%만 써야 한다.
- 실제 회사명과 실제 업무 데이터가 화면과 음성에 없는지 확인한다.
- 촬영에서 계수와 대조와 차이 목록과 조치 우선순위와 리포트까지 순서가 끊기지 않는지 확인한다.
- 총 길이가 3분 안에 드는지 확인한다.
